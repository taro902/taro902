## 🛡️ House Rules

1. Names come from drivers and error messages. Vibes have never compiled.
2. Every bound ships with a witness; hunches wait in the scratch branch.
3. One kernel, many public names. Copy-paste is a confession and I don't confess.
4. Broken visuals get purged the day they are caught. This profile keeps a body count of renderers.
5. The judge owns the milliseconds; I own the work per testcase. We don't argue about it.
